Privacy Policy

Last updated: October 2026

1. No Data Collected

oneqr collects nothing. No accounts, no cookies, no analytics, no tracking pixels, no server logs tied to you. The site is a set of static files.

2. Your Links Stay in the URL

The social links you add are encoded into the QR code link itself (the part after #). That fragment is never sent to any server — your browser reads it locally. We never see, store, or transmit your links.

3. Third-Party Hosting

Pages are served by GitHub Pages. GitHub may collect standard server logs (such as IP addresses) per its own privacy statement. We do not receive or process those logs.

4. Advertising (Future)

If display ads are added later, the ad provider may use cookies as described in its own policy. This policy will be updated before any ad code ships.

5. Children

The service is a general-purpose utility with no age gate and no data collection, and collects nothing from anyone including children.

6. Contact

Questions about this policy: open an issue on the project repository.
